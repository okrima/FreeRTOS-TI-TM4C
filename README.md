# FreeRTOS Project for TI TM4C
This repository contains a demonstration firmware application based on **FreeRTOS**, developed for the Texas Instruments Tiva C family microcontroller. The firmware is structured as a foundation for controlling analog and digital signals.

## 💻 Hardware Reference

*   **Board:** Tiva Launchpad EK-TM4C1294XL
*   **Microcontroller:** TI TM4C129NCPDT
*   **System Clock:** Configured via PLL to operate at 120 MHz
*   **Initialized Peripheral Drivers:** ADC, Digital I/O, PWM, Timers, and Zero Cross Phase Cut (ZCPC). The system also verifies the presence of a hardware expansion (S13 board) at boot.

## ⚙️ FreeRTOS Architecture

The firmware leverages the Real-Time Operating System to separate low-level hardware management from the application logic, utilizing several Tasks:

*   **`1MS_TASK` (High Priority):** A periodic task waking up every millisecond (`vTaskDelayUntil`) to manage global timers and orchestrate serial communication.
*   **`MAIN` Task (Application Logic):** Executes a continuous loop handling the status LED blinking, updating physical I/O status (`RefreshInput()`, `RefreshOutput()`), and calling the main control logic (`Controller()`).
*   **Driver Ticker Tasks:** Background tasks dedicated to hardware driver refresh (`ADC_TICK`, `DIG_TICK`, `TIMER_TICK`, `ZCPC_TICK`).

## 🛠️ Features and Implemented Modules

### 1. I/O Acquisition and Control
The firmware manages a wide set of inputs and outputs, mapping logical and physical values:
*   **Analog Inputs:** Reading and converting PTC and PT1000 temperature probes using specific pre-set calculation tables.
*   **Analog Outputs:** Command signal generation (including DC/AC fan management via Triac pulse lengths).
*   **I/O Logic (Controller Module):** Currently, the `Controller.c` file implements a test environment that scans digital input statuses and maps them directly to the corresponding digital outputs.

## 🔧 Security and Debugging
The system includes FreeRTOS system hooks to prevent critical errors:
*   `vApplicationStackOverflowHook`: Infinite loop handling in case of task stack overflow.
*   `__error__`: Custom `ASSERT` function to intercept any errors generated by the Texas Instruments driverlib libraries.
